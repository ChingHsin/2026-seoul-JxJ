## 1. Overview & Core Concept

- **核心定位**：結合「隨身離線旅遊手冊 PWA」與「零配置靜態部署產生器」的雙效工具。
- **目標使用者與情境**：2026 年 10 月底至 11 月初赴首爾 6 天 5 夜自由行的女性獨旅者。在金浦機場出關、孔德與堂山跨區移動、INSPIRE Arena 演唱會接駁、聖水洞與漢南洞採買，以及樂天超市與超商寄件時，可單手快速查閱動線、勾選清單、換算匯率並控管行李重量。
- **核心價值**：
  1. **動線與住宿無縫銜接**：清楚標示「堂山朋友家 ↔ 孔德 GLAD Hotel Mapo」的行李寄放與移動節點，避免演唱會日與跨區移動時帶著大件行李奔波。
  2. **精準物流與刷卡決策**：針對每筆戰利品自動建議最佳支付卡片（星展 eco 5%、富邦 J 卡登錄 6%、國泰 CUBE 3%、TWQR 超商掃碼）與物流分流（託運 vs. 集運倉）。
  3. **一鍵自動化發布（CI/CD）**：內建部署工作台，直接檢視並下載 `.github/workflows/deploy.yml`、`.nojekyll`、`netlify.toml` 與完整單檔 `index.html`，推送至 GitHub `main` 分支即可自動發布。

## 2. User Experience & Visual Design

### 關鍵使用者流程 (Key User Flows)
1. **每日行程與攝影時間軸 (Day 1 – Day 6)**：
   - 頂部提供氣溫/穿搭提示與當日住宿、行李狀態摘要（如 Day 2 晨間拍德壽宮銀杏 ➔ 孔德寄放行李 ➔ 聖水洞採買；Day 5 波拉美 YONEX 搶購 ➔ 漢南洞香氛 ➔ 首爾路 7017 夕陽 ➔ 樂天超市退稅裝箱 ➔ 超商寄集運）。
   - 每個行程節點支援點擊「完成打勾」（自動儲存至 LocalStorage），並可展開查看拍攝機位建議、退稅提醒與交通轉乘細節，亦可直接在介面中新增或編輯個人備忘。
2. **工具箱與戰利品行李配重 (Tools & Logistics Hub)**：
   - **即時雙向匯率換算器**：支援韓元 (KRW) 與台幣 (TWD) 雙向即時輸入換算，內建常用金額快捷鍵（如 10,000₩、30,000₩、50,000₩ 退稅門檻）與自訂匯率微調。
   - **戰利品記帳與 15kg 行李配重試算器**：新增戰利品時可輸入名稱、韓元金額、預估重量 (g/kg)、分類（液體美妝 / 服飾鞋盒 / 羽球裝備 / 零食伴手禮）與歸屬位置（20 吋託運箱 15kg / 隨身擴充袋 10kg / 超商寄集運倉）。系統即時以視覺化進度條顯示 15kg 託運與 10kg 隨身剩餘扣打，並推薦最適刷卡方式。
   - **互動式打包與朝聖清單**：分類管理「行前必備/液體規範」、「同款朝聖打卡點」、「必買目標清單（SW19 香水、BANILA CO 卸妝膏、Musinsa 2 折特價、YONEX KR 版羽球服、Mardi Mercredi）」，支援進度統計與自訂新增項目。
3. **CI/CD 自動化部署與單檔匯出中心 (Deploy & Export Center)**：
   - 清楚圖解 GitHub Pages 根目錄部署步驟（解決 `/docs` Jekyll 報錯問題）。
   - 提供一鍵下載目前已同步最新資料的**單一檔案 `index.html`**、**`.github/workflows/deploy.yml`**、**`.nojekyll`** 與 **Netlify 設定指南**。

### 視覺識別與主題 (Visual Identity & Theme)
- **美學定調**：首爾秋日銀杏與韓系編輯雜誌感（Seoul Autumn Editorial）。以溫暖紙質感為基底，搭配銀杏金與深秋楓紅點綴，營造兼具質感與實用效率的閱讀體驗。
- **色彩系統 (60-30-10 原則)**：
  - `60% 主體畫布 (--background)`：暖米白韓紙色 (`#FAF7F2`)，降低長時間閱讀疲勞。
  - `30% 結構表面與文字 (--surface / --foreground)`：柔和燕麥白卡片 (`#FFFFFF` 搭配細緻暖灰邊框 `#E8E2D9`) 與深炭焙茶色主文字 (`#231F1E`)、次要暖灰文字 (`#6E655F`)。
  - `10% 焦點強調色 (--primary / --accent)`：德壽宮銀杏琥珀金 (`#D48C28`) 與昌慶宮秋楓磚紅 (`#B84A39`)，用於當前選中分頁、關鍵提醒與重要按鈕。
- **字體排印與階層 (Typography & Hierarchy)**：
  - 標題字體：具人文雜誌韻味的襯線與現代黑體搭配（`Noto Serif TC` / `Plus Jakarta Sans`），呈現首爾秋季旅遊誌的精緻標題。
  - 內文字體：清晰易讀的繁體中文無襯線體（`Noto Sans TC` / `DM Sans`），行高 `1.6` 確保行動端舒適閱讀。
  - 數據與金額：全面啟用等寬對齊數字（`JetBrains Mono` + `tabular-nums`），確保匯率換算、時間軸時刻、15kg 重量進度與記帳金額垂直對齊。
- **行動端單手操控設計 (Mobile-First & Thumb Ergonomics)**：
  - 所有互動按鈕、分頁切換與勾選框皆符合 $\ge 44 \times 44\text{px}$ 觸控熱區標準。
  - 底部固定導覽列（行程時間軸、行李與記帳、匯率與刷卡、打包與朝聖、部署與匯出）與頂部精簡狀態列總高度嚴格控制在視窗高度 `15%` 以內，保留最大可捲動閱讀空間；在桌面端（1440px）則自動展開為雙欄式雜誌版面，不侷限於窄小手機框。

## 3. Key Product Decisions & Trade-Offs

- **決策 1：模組化 React PWA 搭配動態單檔 `index.html` 產生器**
  - *選擇方案*：在開發環境中採用結構清晰的模組化架構（支援 PWA Service Worker 離線快取與主畫面安裝），同時內建一個可將當前行程、清單與工具完整打包輸出為獨立 Vanilla HTML/CSS/JS `index.html` 的匯出引擎。
  - *原因*：單一龐大 HTML 檔案在後續擴充功能（如配重試算器、自訂行程編輯）時較難維護；透過模組化維護並支援一鍵匯出純靜態單檔 `index.html`，能同時享有現代 PWA 的流暢體驗與 GitHub Pages 零依賴部署的絕對穩定性。
- **決策 2：LocalStorage 本地持久化搭配 JSON 備份/還原**
  - *選擇方案*：所有打勾狀態、自訂匯率、戰利品記帳與行李配重資料皆即時寫入瀏覽器 `localStorage`，並提供 JSON 匯出/匯入與重置功能。
  - *原因*：海外旅遊時網路可能不穩（如仁川 INSPIRE 場館內或地鐵移動中），純本地儲存搭配 PWA 離線快取可確保零延遲且 100% 離線可用。
- **決策 3：GitHub Actions 官方 Pages Artifact 部署流程 + `.nojekyll` 雙重保險**
  - *選擇方案*：提供標準 `.github/workflows/deploy.yml`（使用 `actions/upload-pages-artifact` 與 `actions/deploy-pages`），並搭配根目錄 `.nojekyll` 檔案。
  - *原因*：徹底繞過 GitHub Pages 預設的 `/docs` 資料夾限制與 Jekyll 編譯器，只要 `git push` 至 `main` 分支即可在 30 秒內自動完成靜態網頁部署，同時也相容 Netlify / Vercel 的 Git 自動觸發部署。

### 資料模型與狀態管理 (Data Model & State)
- **`ItineraryDay` (每日行程結構)**：包含日期 (`10/29`–`11/03`)、主題標籤、當晚住宿（堂山朋友家 / 孔德 GLAD Mapo）、行李策略提示，以及時間軸項目陣列（時間、地點、分類標籤、攝影/購物重點、交通方式、是否已完成勾選）。
- **`LootAndLuggageItem` (戰利品與行李配重項目)**：包含品名（預設內建 SW19 香水、BANILA CO 卸妝膏、YONEX KR 羽球服、Musinsa 服飾、Mardi Mercredi、樂天超市零食等可一鍵帶入或新增）、韓元價格 (`priceKrw`)、重量公克 (`weightGrams`)、行李分流 (`checked_15kg` 20吋託運 / `carryon_10kg` 隨身擴充袋 / `courier_box` 超商寄集運倉)、推薦支付方式與已購買狀態。
- **`ChecklistItem` (打包與同款朝聖清單)**：分為「行前與隨身必備」、「託運與液體規範」、「追星同款朝聖打卡」、「必買購物清單」四大類，支援勾選記憶與自訂新增。
- **`CurrencyState` (匯率換算狀態)**：預設基準匯率（如 `1 TWD = 42.5 KRW` 或 `KRW ÷ 42.5`），支援使用者即時修改匯率並記憶於本地端。

### 互動元件與狀態對應 (Interactive Component & State Mapping)
- **時間軸勾選與自訂筆記**：點擊任一行程節點可切換完成狀態並觸發平滑視覺回饋；點擊「新增備忘」可在當日時間軸插入自訂行程或拍攝筆記。
- **15kg 託運 / 10kg 隨身 / 集運倉動態試算**：當使用者新增或勾選戰利品時，系統自動加總各分流重量：
  - 若液體類被誤選為「隨身擴充袋」，系統會主動顯示溫馨提醒：「超過 100ml 液體（如卸妝膏/大瓶香水）請歸入 20 吋託運箱」。
  - 當 20 吋託運箱接近或超過 `15,000g (15kg)` 時，進度條由銀杏金轉為楓葉紅警示，建議將非液體衣物或鞋盒改選為「CU/GS25 超商寄首爾集運倉」。
- **CI/CD 與單檔匯出引擎**：點擊「下載獨立 `index.html`」時，系統會將目前的行程資料、清單項目、雙向匯率換算器與配重試算器完整封裝為零外部依賴的單一 HTML 檔案直接下載；同時提供一鍵複製或下載 `.github/workflows/deploy.yml` 與 `.nojekyll`。
